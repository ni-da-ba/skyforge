# Security Policy

## Supported versions

Skyforge is a pre-release engineering project. No version currently receives a stable compatibility or long-term security-support guarantee. Security fixes are applied to the active `main` branch as appropriate.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or accidentally exposed credential.

Use GitHub's private vulnerability-reporting channel for this repository:

<https://github.com/ni-da-ba/skyforge/security/advisories/new>

Include the affected commit or version, reproduction steps, likely impact, and any suggested mitigation. Please avoid publishing proof-of-concept exploitation until the issue has been assessed and a reasonable remediation window has passed.

Ordinary correctness defects, terrain-generation behavior, and non-sensitive compatibility problems belong in the public issue tracker.
