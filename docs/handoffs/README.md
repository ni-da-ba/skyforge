# Skyforge Historical Handoffs

This directory retains milestone-specific historical handoff records.

Current live agent state is **not** maintained here.

Fresh agents should read:

1. [the canonical program charter](../agent-state/PROGRAM_CHARTER.md);
2. their lane state under [`docs/agent-state/`](../agent-state/README.md);
3. [the cross-lane contracts](../agent-state/CROSS_LANE_CONTRACTS.md);
4. relevant current source, tests, PRs, issues, and merged history.

Historical handoffs remain useful evidence for the milestone they describe, but they must not be treated as current lane state when they disagree with `main`.
