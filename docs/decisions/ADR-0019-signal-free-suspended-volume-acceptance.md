# ADR-0019: Signal-free suspended-volume acceptance

**Status:** Accepted
**Date:** 2026-08-27
**Ticket:** SF-IMP-0015

## Context

ADR-0017 accepted the analytical signal-free suspended-volume recipe and ADR-0018 accepted the
canonical three-dimensional evidence format, but neither made one generated specimen a permanent
regression contract. SF-IMP-0015 must execute the signal-free `SF-VOL` gates, distinguish the
claims that are now proven from the seeded-enrichment gate that is not yet in scope, and pin the
accepted evidence bytes without making engine-version metadata part of morphology identity.

The acceptance source is the Java 25 CI artifact generated from protected `main` commit
`4464d20c6a1c918cef2442ee1b6e593cbf3d0bbf`. That run completed successfully and produced the
canonical `signal-free-suspended-volume-v1` evidence package.

## Decision

1. Accept the canonical descriptor and `193 x 129 x 193` evidence domain already fixed by
   ADR-0016 and emitted by SF-IMP-0014.
2. Execute `SF-VOL-001` through `SF-VOL-005` and `SF-VOL-007` through `SF-VOL-010` as executable
   JUnit acceptance tests. `SF-VOL-006` remains deferred to SF-IMP-0016 because the signal-free
   recipe intentionally rejects nonzero signal amplitude.
3. Accept the following canonical morphology facts at the declared four-unit sampling resolution:
   - 366,912 positive-density samples;
   - exactly one face-connected solid component;
   - zero positive-density samples on all six domain faces;
   - sampled solid bounds `x = [-296, 296]`, `y = [128, 348]`, `z = [-236, 236]`;
   - minimum sampled air clearance of 88 world units.
4. Require forward, reversed, permuted, batched, and parallel evaluation to produce the identical
   canonical density-volume SHA-256
   `b608b42a93dc8ae9955ffab293b4a5e395a18d9322aaddd00e9f37ee5e80d8a7`.
5. Pin 19 deterministic artifacts as the golden specimen: descriptor, three graphs, provenance,
   density and occupancy volumes, three horizontal grids, two exact vertical-slice CSV files, six
   review PNGs, and the HTML gallery.
6. Exclude `manifest.json` from the golden path set because it contains engine-version metadata.
   Exclude `evidence.sha256` because it includes the manifest hash. Both files remain generated and
   inspectable but are not morphology identity.
7. Treat the PNG hashes as part of the accepted Java reference evidence environment, while
   retaining numerical grids, topology metrics, and exact graph bytes as the authoritative proof.
8. Preserve the released v0.1 contract unchanged. The acceptance suite checks that the 49-path
   v0.1 golden resource remains present, while CI continues to regenerate and verify that corpus.

## Consequences

- Skyforge now has a permanent backend-neutral proof of one finite signal-free mass suspended in
  air rather than merely a top-down terrain surface.
- A plausible review image cannot silently replace the accepted geometry: graph bytes, volume
  bytes, topology, clearances, slices, and provenance are pinned alongside it.
- Changes to the accepted primary morphology must explicitly replace or version this golden
  specimen rather than mechanically updating hashes.
- Seeded enrichment is now the only incomplete gate in the v0.2 suspended-volume boundary.
  SF-IMP-0016 must preserve closure, connectedness, clearance, and primary identity across its
  fixed seed suite before secondary ridges, valleys, or multi-morphology composition begin.

## Compatibility

No released v0.1 descriptor, graph schema 1 or 2 encoding, fixed-seed path, or golden checksum is
changed. Graph schema 3 and the signal-free volume recipe remain exactly as accepted by ADR-0016
and ADR-0017. This ADR accepts evidence produced by those contracts; it does not alter them.
