# Dimension Realization Value Audit v0.1

**Snapshot:** 2026-09-05
**Status:** Comparative decision audit for Overworld, Nether, and End.

## Decision question

> Does each dimension provide enough unique, repeatable, infrastructure-generating gameplay to justify full Skyforge realization?

A dimension should not receive full bespoke world-authorship effort merely because:

- it exists in vanilla;
- its terrain could look impressive;
- Skyforge is technically capable of generating it.

Full realization is justified when the dimension creates a durable gameplay system.

## Realization-worth test

A dimension should satisfy most of the following.

### W1 — unique gameplay job

The player makes decisions here that they would not make elsewhere.

### W2 — unique capability payoff

The dimension unlocks at least one meaningful capability, not merely decorative blocks.

### W3 — repeatable value

The player has rational reasons to return after the first major unlock.

Repeatability may come from:

- renewable production;
- continued extraction;
- repeated expeditions;
- farming;
- recurring encounters;
- services;
- logistics.

It does **not** have to be bulk commodity throughput in every dimension.

### W4 — infrastructure demand

Building:

- bases;
- routes;
- depots;
- workshops;
- farms;
- navigation;
- repair/recovery sites;

materially improves play.

### W5 — engineering specialization

The environment rewards different:

- vehicles;
- structures;
- processes;
- safety margins;
- navigation techniques.

### W6 — logistics identity

Movement of players/resources/machines through the dimension is not a solved triviality.

### W7 — structure/encounter depth

Structures are more than isolated loot boxes and can participate in regional/site meaning.

### W8 — failure/recovery game

The player can engineer around dimension-specific failure modes.

### W9 — cross-dimensional economy

The dimension exports something worth importing and imports something worth supplying.

### W10 — Skyforge authorship payoff

Semantic world synthesis can materially improve gameplay over leaving the dimension under vanilla random generation.

## Comparative verdict

| Dimension | Current verdict | Main strength | Main unresolved issue |
|---|---|---|---|
| Overworld | **FULL REALIZATION JUSTIFIED** | complete living + aviation + logistics world | avoid monopolizing all progression value |
| Nether | **STRONG CONDITIONAL YES** | hostile route engineering + structures + processing/resources | prove enough persistent multi-node operations after early progression |
| End | **PROMISING CONDITIONAL YES** | expeditionary aviation + Levitite + severe negative-space logistics | prove enough post-Elytra/Shulker/first-Levitite reasons to keep operating there |

## The dimensions should specialize differently

The target is not equal content volume.

It is equal **design legitimacy**.

### Overworld — broad economy

The Overworld can support many routine systems simultaneously.

Value type:

~~~text
BREADTH
+
PERMANENCE
+
NETWORK
~~~

### Nether — operational depth

The Nether can support fewer kinds of ordinary life while making routes/sites more demanding.

Value type:

~~~text
ACCESS
+
RISK
+
EXTRACTION
+
PROCESS
~~~

### End — expeditionary depth

The End can remain sparse while making each long-range operation meaningful.

Value type:

~~~text
DISTANCE
+
RISK
+
SPECIAL TECHNOLOGY
+
EXPLORATION
~~~

Do not try to give the End an agricultural economy merely to equalize the Overworld.

Do not fill the Nether with settlements merely to equalize civilization count.

## Cross-dimensional production should be deliberate

The strongest existing example is Levitite:

~~~text
OVERWORLD
    zinc + general Create industry

NETHER / CREATE PROGRESSION
    heat / soul-fire context can participate

END
    End Stone feedstock

    -> advanced aeronautical material
~~~

This is desirable.

It makes the dimensions parts of one industrial civilization rather than independent campaigns.

### Design rule

Prefer:

~~~text
Dimension A supplies material
Dimension B supplies process/catalyst
Overworld supplies mature industry
-> new system capability
~~~

when this emerges naturally from selected mods.

Avoid contrived three-dimension recipe chains whose only purpose is forcing travel.

## Infrastructure is the real late-game reward

The player's long-term progression should increasingly become:

~~~text
I can go there
    -> I can survive there
    -> I can return reliably
    -> I can build there
    -> I can operate there
    -> I can integrate it into my network
~~~

This is a better maturity model than:

~~~text
I found the next ingot color.
~~~

## Realization-cost discipline

Full Skyforge authoring is expensive.

Therefore use staged proof.

### Stage R-DIM-0 — gameplay paper audit

Current phase.

Define:

- jobs;
- rewards;
- loops;
- risks;
- infrastructure.

### Stage R-DIM-1 — vanilla/modded play proof

Before custom terrain, test the selected stack in ordinary dimensions.

Measure:

- actual demand;
- vehicle behavior;
- farms;
- transfer;
- routes;
- failure.

### Stage R-DIM-2 — bounded Skyforge pilot

One controlled authored region.

### Stage R-DIM-3 — structure/resource integration

Prove critical structures and resources.

### Stage R-DIM-4 — repeatability proof

Play beyond the first unlock.

Ask:

> Would I voluntarily return/build here?

### Stage R-DIM-5 — full realization

Only then expand the authored grammar.

## Current implementation priority

### 1. Overworld

Continue as current primary implementation.

### 2. Outer End bounded pilot

Preferred first cross-dimension Skyforge proof because:

- current suspended-volume machinery transfers;
- Aeronautics gives a real dimension-specific technology loop;
- negative-space composition is central;
- critical Dragon arena can remain isolated under vanilla/special authority.

### 3. Nether bounded cavern/route pilot

Follow with a pilot that deliberately stresses assumptions the End shares with islands:

- solid-dominant composition;
- negative-space ownership;
- route connectivity;
- structure embedding;
- lava;
- constrained aviation.

The ordering is architectural efficiency, not a judgment that the End is more important than the Nether.

## Final doctrine

> A dimension does not need the same amount of content as another dimension.

It needs enough **consequential choices**.

The Overworld can be worth inhabiting.

The Nether can be worth operating.

The End can be worth mastering.

If each achieves that, full Skyforge realization is justified.

## Acceptance principle

> Fully realize a dimension only when the player's desire to build systems there is stronger than the designer's desire to generate terrain there.
