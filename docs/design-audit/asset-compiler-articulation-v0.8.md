# v0.8 architectural articulation

This pass promotes several lessons from the v0.4-v0.7 Minecraft reviews into a named compiler stage instead of leaving them as ad-hoc corrections.

The stage owns three bounded concerns:

1. **Proportion evidence.** It computes scale-free architectural ratios and compares them against a provenance-labelled reference profile.
2. **Depth vocabulary and joints.** It validates ordered facade depth planes and places restrained structural-joint articulation at existing bay/post rhythm.
3. **Controlled history.** It permits one deterministic, semantically explained intervention rather than random decorative noise.

This still does not attempt a universal architecture solver. It remains one Guild-branch family and one working-reference profile. The point is to prove that craft knowledge can become inspectable, testable compiler data without claiming more evidence than we have.
