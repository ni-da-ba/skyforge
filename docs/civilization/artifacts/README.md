### Required human decision

Review the same Open Sky identity across:

1. full facade / monumental application;
2. hanging sign;
3. vertical flag/banner;
4. aircraft tail/hull marking;
5. crate/equipment stamp;
6. monochrome carving/etching;
7. approximate 7×7 Minecraft-pixel realization.

PASS when:

- all applications are immediately traceable to one institutional mark;
- the open sky field, navigation star, upward-opening wing/cradle identity survives simplification;
- monochrome remains legible;
- low-resolution use is recognizable without relying on navy/brass color.

The gate is **recognition/legibility, not a redesign invitation**. If one application fails, first attempt bounded application-specific simplification before reopening the locked core geometry.
