# AUTH-0021 — Propagate Naturalized Island Domain

AUTH-0021 promotes the accepted AUTH-0020 morphology-aware island domain from an inspectable candidate into the authoritative ownership geometry for current island-local authorship.

## Dependency

~~~text
SkyIslandDescriptor
    -> AUTH-0020 naturalized island domain
    -> AUTH-0021 current semantic field ownership
        -> elevation / temperature / moisture / exposure
        -> ecology
        -> local hydrology
        -> watershed active domain
        -> retained water / channels
        -> coherent hydrologic realization
        -> continuous hydrologic terrain
~~~

This is a causal-root migration. Downstream planners do not receive a new backend-facing shape flag. They continue to consume the semantic field abstraction and therefore inherit the new ownership geometry naturally.

## Current versus historical composition

SkyIslandSemanticFieldSet.create(descriptor) now uses SkyIslandNaturalizedDomainField for interiority.

SkyIslandSemanticFieldSet.createLegacyCircular(descriptor) preserves the historical AUTH-0002 circular-domain interpretation for accepted diagnostic reproduction only.

The legacy composition is not current authorship.

AUTH-0002 semantic-field evidence and the AUTH-0020 legacy-versus-candidate comparison are explicitly pinned to the legacy factory so those corpora retain their original meaning.

## Semantic consequences

The naturalized domain now affects more than visualization.

Outside the current domain:

- interiority is zero;
- elevation tendency is zero;
- local hydrology returns zero runoff/retention/drainage/outflow;
- ecology has no owned ecological regime and resolves through the existing outside/barren path;
- watershed planning does not activate cells;
- continuous hydrologic terrain fades to zero.

Near the naturalized edge, exposure, moisture retention, temperature-through-elevation, and hydrologic outflow respond to the new local boundary rather than a nominal circle.

## Watershed consequence

AUTH-0005 still evaluates a deterministic 49 x 49 planning lattice across the nominal-radius square.

Only cells whose current naturalized interiority exceeds the accepted active threshold participate in spill routing.

This means the routing mathematics is unchanged while the active drainage domain becomes morphology-aware.

A SPINE therefore drains as an elongated island rather than as a circular island containing a spine-shaped elevation signal.

## Hydrology tranche relationship

AUTH-0021 does not reopen the first island-local hydrology tranche algorithmically.

The accepted runoff, watershed, retained-water, channel-coherence, riparian, drop, terrain-influence, surface, interpolation, and naturalization algorithms remain intact.

They are re-evaluated under a better upstream island domain.

If the new domain exposes a concrete hydrology defect, that defect can become a new requirement. AUTH-0021 should not otherwise resume incremental river tuning.

## Evidence

The authorship-naturalized-domain-propagation-v1 corpus uses representatives covering all five built-in morphology families and both previously pathological hydrology examples.

Each specimen renders:

- CURRENT ELEVATION — semantic elevation clipped and edge-faded by the naturalized domain;
- CURRENT ECOLOGY — semantic ecological regimes only on owned terrain;
- COHERENT HYDROLOGY — current continuous hydrologic terrain plus the coherent visible river skeleton.

manifest.csv records current watershed-cell count, coherent component/reach counts, riparian cells, drop events, waterbody footprints, and hydrologically changed coarse terrain cells.

## Acceptance gate

Reject AUTH-0021 if:

- current semantic ownership still follows the old circle;
- historical AUTH-0002/AUTH-0020 comparison evidence silently changes meaning;
- watershed cells occur outside current ownership;
- continuous hydrologic terrain leaks materially into legacy-circle-only space;
- SPINE or LOBED loses the morphology identity accepted in AUTH-0020;
- naturalized edges produce obvious disconnected ecology or hydrology artifacts;
- the 512/811 coherent-river correction regresses into rake-like visible networks;
- backend-specific concepts enter the semantic/world layers.

## Next front
