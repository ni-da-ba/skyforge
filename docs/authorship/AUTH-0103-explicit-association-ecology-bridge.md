# AUTH-0103 — Explicit authored-realization ecology bridge

## Purpose

DR-40 / issue #494 exposed a concrete production-consumer gap. `P2_DRESSED_REGION_A` is an accepted
SF-IMP-0068 schema-2 runtime volume with an exact AUTH-0046 authored descriptor ↔ realized-volume
association, but that volume was not produced by the AUTH-0058 proof-backed publication pipeline.
AUTH-0087 therefore cannot truthfully be manufactured around it merely to reach AUTH-0088/0090/0092.

AUTH-0103 closes only that identity/projection gap. It does not add ecology meaning.

## Exact boundary

AUTH-0103 accepts an explicit `SkyIslandAuthoredRealizationCatalog` and adds publication-independent
siblings for:

- exact world-X/Z surface ecology projection;
- exact AUTH-0089 catalog aggregation using AUTH-0090's area-weighted math;
- raw nearest-neighbor isolation using AUTH-0092's distance/tie semantics.

AUTH-0091 remains directly consumable from each exact associated authored descriptor. AUTH-0011 remains the accepted riparian-corridor source for flowing-water response; AUTH-0103 does not re-plan hydrology.

The existing published APIs remain publication-gated. AUTH-0088 still requires an AUTH-0087 binding,
and AUTH-0090/AUTH-0092 still expose AUTH-0058 publication identity. Shared projection/aggregation
internals prevent the explicit-association and published paths from drifting.

## No identity inference

The bridge never discovers an association from position, bounds, seed, morphology, list order, or
backend encounter order. Unknown realized volume IDs fail closed. The canonical DR-40 association is
explicitly the DR-00 authored identity `(world=0x534B59464F524745, province=8, cluster=81, island=1471)`
paired with realized volume `6001989086914692933/sf-imp-0068-production-composed-cave/0/0/680068`.

## Ecology semantics

Surface projection preserves AUTH-0088 exactly:

- world X/Z translates through the exact associated realized center;
- a positive compiled physical column is required;
- current authored `interiority > 0` is required;
- the result is the exact AUTH-0003 ecology sample;
- no physical Y or backend identity enters Authorship.

Catalog opportunity preserves AUTH-0089 island profiles and AUTH-0090 horizontal-area weighting.
Isolation preserves AUTH-0092 raw center-distance / nominal-radial-gap evidence and canonical tie
ordering. A singleton association catalog has no nearest neighbor and therefore no fabricated
isolation distance.

## DR-40 interpretation

AUTH-0003 already incorporates authored temperature, moisture, elevation tendency, exposure,
interiority, ecological potential, and hydrological potential. DR-40 must not invent a second
altitude/moisture ecology formula.

AUTH-0092-style isolation is evidence only. No accepted Content policy maps raw isolation to species,
density, carrying capacity, predator pressure, or population rhythm. The canonical singleton's
absence of a peer is therefore diagnostic provenance, not permission to invent population policy.

SF-IMP-0080 remains the accepted visible Minecraft ecology carrier seam. AUTH-0088 already leaves ecological-regime-to-registered-biome mapping to the adapter, so DR-40 needs no new Content biome taxonomy before machine composition. AUTH-0011 may supply exact riparian dry-land response where the canonical hydrology contains it. Backend biome choice,
population scheduling, persistent mutation, exact-volume lifecycle, and diagnostic counts remain
Implementation-owned under #494.

## Explicit non-goals

AUTH-0103 adds no:

- ecology regime or threshold;
- species/entity identity;
- biome key;
- spawn/density/carrying-capacity rule;
- predator/trophic policy;
- resource policy;
- aesthetic ranking;
- publication identity for non-published runtime volumes.

## Acceptance

Reject AUTH-0103 if it weakens AUTH-0087, accepts inferred associations, changes AUTH-0003/0089/0091
formulas, changes AUTH-0090 area weighting, changes AUTH-0092 distance/tie semantics, or introduces
backend/population policy.

Machine evidence must prove parity between the published and explicit-association paths on the same
AUTH-0087 fixture, fail-closed exact-volume routing, singleton isolation with no fabricated neighbor,
and exact construction of the canonical DR-00 association.
